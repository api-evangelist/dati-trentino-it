# Open Data Trentino (dati-trentino-it)

Open Data Trentino is a open data portal open-data portal for Italy running **CKAN**, exposing a standardized catalog API over ~1,381 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/dati-trentino-it/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=dati-trentino-it-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.9.5

## API
- **Open Data Trentino CKAN Action API** — base `https://dati.trentino.it/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://dati.trentino.it)
- Live endpoint verified: `https://dati.trentino.it/api/3/action/status_show` · ~1,381 datasets
